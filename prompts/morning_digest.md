# morning_digest — 每日晨报

由 cron 按 `settings.yaml: digest.schedule` 触发。

## 输入

1. `config/settings.yaml`
2. `data/raw/` 最近 `lookback_hours` 的帖子
3. `data/raw/` 最近 `hot_topic_window_hours`（7天）的帖子 —— 叙事检测必须看长窗口
4. `state/quota.json`（昨天实际发了几条，用于校准）
5. 前一份 `data/digests/*.md`（避免重复推荐同一选题）

数据不足时明确说"数据不足"，**不要用推测填补**。

## 第一部分：叙事收敛检测（晨报的核心）

目标不是"昨天什么帖子火了"，而是"**圈内的注意力正在往哪里移动**"。

### 收敛 vs 回声（必须区分，这是最容易出错的地方）

- **回声**：一个人发了爆帖，其他所有人转发/引用他。这是单点放大，**不是**热点。
  → 识别方法：追溯这些帖子是否指向同一个源头 post_id。若是，标记为回声。
- **收敛**：3 个以上**互不引用**的账号，在 `convergence_window_hours` 内**独立**提到同一件事。
  → 这才是真拐点，说明底层发生了变化，而不是某个帖子火了。

按 `signal.convergence_min_accounts` 判定。只统计互动量 ≥ `min_engagement_for_signal` 的帖子，避免噪音。

### 对每个收敛信号，输出

- **信号名**：一句话，用圈内人会用的词
- **强度**：出现账号数 / 时间跨度 / 是否仍在加速
- **拐点判断**：是新出现的，还是已持续多日？（对比 7 天窗口的前半段）
- **谁在说**：列出账号 + tier。**每个都必须能追溯到具体帖子**，附 post_id 或 URL
- **反方**：有没有人明确不同意？分歧点是什么？（分歧比共识更有选题价值）
- **数据缺口**：这个叙事还缺什么证据？—— 这是最好的选题切入点

最多 `digest.max_topics` 个，按强度降序。

## 第二部分：关键词提取

从收敛信号中抽取：
- **上升关键词**：本周出现频次显著高于上周的词（给出两个窗口的实际计数，不给感觉）
- **新术语**：第一次出现或刚开始被复用的说法 —— 早期采用这些词有搜索红利
- **项目/协议名**：被多个独立账号提到的具体项目
- **人物**：新进入讨论中心的人（可能值得加进 `accounts.yaml`）

每个关键词标注**实际出现次数和来源帖子**。计数不足的不列。**不许把"我觉得会火"包装成关键词趋势。**

## 第三部分：选题建议

`digest.content_angles_per_digest` 个。每个必须包含：

- **角度**：具体到能直接开写，不是"写一篇关于 RWA 合规的文章"
- **为什么是现在**：绑定到第一部分的哪个收敛信号，时间敏感性在哪
- **为什么是你**：必须用到 `identity.angle`。如果这个角度换成任何别的账号都能写，**换掉**
- **反共识点**：你能说的、和主流叙事不完全一致的那一句
- **形式**：单帖 / 长推串 / 图文 / 数据帖
- **发布窗口**：具体时间段 + 理由（基于名单账号的历史活跃时段，用实际数据算，不要瞎猜）
- **需要补的数据**：写之前你要去核实什么

不重复前一份晨报已推荐过的角度，除非有新进展 —— 若有，说明进展是什么。

## 第四部分：昨日复盘

用实际数据，不要空话：
- 昨天发出的回复数 / 额度（`quota.json`）
- 这些回复拿到的互动（若 `scripts/stats.py` 可取到）
- 哪个策略标签（信息增量/补盲区/压缩…）表现最好
- 错过的机会：有没有高分帖子因为额度或延迟没抢到？—— 用于调 `interval_minutes` 和 `ramp_schedule`
- 账号健康度：有没有被限流的迹象（互动量突然归零、回复不可见）

## 输出

1. 写入 `data/digests/YYYY-MM-DD.md`
2. 对话里输出全文（晨报是给人读的，不要只给路径）

格式要求：可扫读。用短段落和表格。每个事实性陈述都能追溯到帖子或数据文件。
**不确定的地方标注"未核实"，不要为了让报告好看而填数。**
